Accessibility

Access for everyone.

We are working to make the Speedi website easier to use for all visitors.

Effective date: September 22, 2026

Our commitment

Speedi aims to provide a website that people with disabilities can use. We are working toward the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA as a practical accessibility target for this website.

What we are doing

  • Using meaningful text alternatives for important images.
  • Supporting keyboard navigation and visible focus states.
  • Using responsive layouts and readable color contrast.
  • Respecting reduced-motion settings where practical.
  • Reviewing new pages for accessibility issues before publishing.

Need help or found a barrier?

If you have trouble using any part of this website or need information in another format, email contact@speedi.delivery. Please include the page URL, a short description of the issue, your device and browser if you know them, and the best way to contact you. We will work to provide reasonable assistance.

Ongoing work

Accessibility is an ongoing effort. We may update this statement as the website changes or as we improve accessibility features.
